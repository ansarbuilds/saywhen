Code of Conduct

saywhen follows the Contributor Covenant, version 2.1.

In short:

  • Be kind and patient. People here have different backgrounds and different levels of experience.
  • Talk about the work, not the person.
  • No harassment, insults or unwelcome personal attention, in issues, pull requests or anywhere else connected to the project.

Reporting

If someone's behavior is a problem, contact the maintainer privately through the contact details on the maintainer's GitHub profile. Reports are kept confidential. The maintainer may edit or remove comments, and may block people who keep breaking these rules.

Security and privacy problems go through SECURITY.md instead.
